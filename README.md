# Interview Ready Tracker

A local-first tracker for a focused software-engineering internship interview-practice path.

## Run locally

From this folder:

```bash
python3 -m http.server 4173 --directory dist
```

Then open `http://127.0.0.1:4173`.

Progress and notes stay in the browser's local storage. The tracker is intentionally a study organizer, not a code judge or a replacement for LeetCode.
